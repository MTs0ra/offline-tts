# NOT listed here on purpose: onnxruntime-directml (GPU/DirectML support for Kokoro).
# piper-tts and kokoro-onnx both declare a plain `onnxruntime` dependency, but
# onnxruntime-directml installs under a *different* distribution name while providing
# the same `onnxruntime` import - pip's resolver doesn't know one satisfies the other, so
# listing both here would make a fresh `pip install -r requirements.txt` try to install
# real `onnxruntime` right on top of onnxruntime-directml's files, silently breaking GPU
# support. `pip install -r requirements.txt` alone gives you CPU-only, which always works.
# For GPU (DirectML), run this as a manual step *after* the line above, on its own:
#   pip uninstall onnxruntime -y
#   pip install onnxruntime-directml
# kokoro_backend.py detects at runtime whether that swap was done (falls back to CPU
# automatically if not, or if DirectML fails to initialize) - see its module docstring.
